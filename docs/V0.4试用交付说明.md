# V0.4-pilot.1 小范围试用交付说明

## 给谁、发什么

优先给 2–3 位能使用 Codex 和 Windows 的使用者，尝试体量可控的游戏。至少包含一位零经验、一位已有设定资料，尽量覆盖不同玩法。无需等他们完成游戏，先收集首次打开、资料理解、范围讨论和下一步操作的反馈。

分享文件：[游戏开发工作流_V0.4-pilot.1.zip](https://github.com/rainerpj/beginner-game-dev-workflow/raw/refs/heads/master/交付包/游戏开发工作流_V0.4-pilot.1.zip)。它在本地工作树中构建并验证，随后随源码提交到 GitHub；包内的构建来源记录保持构建时事实。包内有 8 个技能、指南、规范、工具、模板、必要示例、空白项目记录与首次操作卡，不含开发者客户资料、游戏工程、反馈、改进历史、备份、旧发布记录或账户信息。首次试用下载此专用包，不使用 GitHub 的源码打包入口。

此包已准备供新项目使用。已有客户项目升级需先备份并按差异合并；严禁把空记录覆盖已有进度。旧 V0.3 交付包不是本版。

## 可以复制的发送文字

> 这是游戏开发工作流的小范围试用版 V0.4-pilot.1，需要你自己的可用 Codex 账户和 Windows 电脑。把 ZIP 完整解压，用 Codex 打开里面能看到 AGENTS.md 的文件夹，再把已有设定发给它，或放进“00_客户资料”。没有资料也能从想法开始。
>
> 对 Codex 说：“请先读我的资料和 AGENTS.md，检查环境，按工作流带我开始。我没有游戏开发经验，每次只告诉我当前需要做的几个动作。”双击“启动进度网页.cmd”能看本地进度；没有 Python 时让 Codex 帮你检查。网页不会自己执行 AI。
>
> 第一次先试到“能打开说明、保存一句反馈、让 Codex 读取并答复”。把卡住的一步、报错或不理解的地方告诉我即可。它仍是早期试用版，不保证自动做完所有类型的游戏；引擎、资源工具和费用按实际项目准备。详细条件和限制在包内“试用说明”。

## 提供者怎样接收反馈

没有在包内设置联网收集、自动发送或支持账号。使用者在网页保存的反馈只留在其本机；需要汇总时请对方主动提供版本号、所处步骤和现象，不默认要求整个私有项目。支持方式和时间另行约定，不承诺包内不存在的服务。

收到反馈后先复现并区分工具故障、引导不清和游戏需求；保留原话与范围，再决定修复。不把本轮合成项目走查或自动测试写成真实新手试用成功。
