## 本轮主要改动

- README/先看这里、客户试用说明与故障路径，通用备份说明和已初始化指引。
- init_project 新增真实首步卡片引用；打包器独立生成新项目交接及空白 state/improvement，不拿当前开发者记录给客户。
- doctor 不再只识别 Unity；识别标识与运行能力分开。
- server 过滤备份文档并在 Windows 独占端口；workflow 原子保存对 Windows 短暂占用作有限重试，持续失败保留原记录。
- CMD 只含 ASCII，调用 start_progress.py；缺 Python 时 type 独立中文提示文件，解决中文批处理截断。
- build_pilot.py 明确来源文件集合、拒绝覆盖 ZIP、包内容检查与清单；测试新增首次使用、兼容性及实际故障回归。
