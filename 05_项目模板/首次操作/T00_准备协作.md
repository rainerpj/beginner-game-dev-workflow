# 第一步：让资料、对话和进度连起来

这是新项目的初始操作卡；尚未验证你的电脑，也不代表游戏已开始制作。AI 读取实际环境后会更新本卡。

## 你现在做什么

1. 用 Codex 打开解压后的整个文件夹（里面应能看到 AGENTS.md 和“启动进度网页.cmd”）。把已有设定发到当前对话或放进 `00_客户资料/`；没有资料也可以开始。
2. 对 Codex 说：“请先读 AGENTS.md 和我的资料，检查环境，告诉我你理解了什么，再带我做下一步。我没有游戏开发经验。”
3. 双击“启动进度网页.cmd”。打开本步说明后，在“我的反馈”保存一句真实情况，例如“我已看到说明，但不知道下一步”。回到 Codex 说“请读取最新反馈”。

## AI 要做什么

读取项目概念、state.json、已有资料和资料接收记录，按首次准备规范预检。核对当前卡片、记录实际能力并用受校验操作更新状态，观察网页同步，读取并答复反馈。客户未实际操作的部分保持待验证，不替客户作答。

## 应该看到什么

网页有本步说明，AI 更新记录后版本号变化；保存的反馈留在列表里，AI 能读到并回答。网页不会自己调用 AI，关闭浏览器不会删除已经保存的记录；关闭服务窗口会停止网页。

不能打开时，先读 [第一次打不开怎么办](../../01_客户指南/07_第一次打不开怎么办.md)。没有 Python 或游戏引擎时，仍可先和 Codex 整理资料；没有可用 Codex 时，先按 [试用说明](../../01_客户指南/10_小范围试用说明.md) 准备条件。不要反复初始化或覆盖记录来排错。
