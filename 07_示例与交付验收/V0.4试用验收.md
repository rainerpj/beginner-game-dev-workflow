# V0.4-pilot.1 试用检查

日期：2026-11-18。目标是准备可给少量使用者开始使用的 Windows 试用包。验证对象是工作流交付包，不是客户游戏。合成场景不是客户决定或真实使用反馈。

## 本版内容

- 统一的完整游戏生命周期与按类型适配，8 个本地技能；原型不能代替完整交付。
- 首次操作卡、已初始化的空白项目记录与新项目交接。无需用户重复初始化；已有记录仍拒绝覆盖。
- 新手试用条件、故障处理、反馈方法和可复制的分享文字；不设置在线反馈收集或自动上传。
- 环境预检识别 Unity、Unreal、Godot、JavaScript/HTML 项目标识；没有引擎也可先做资料与设计。标识存在不代表已编译或运行。
- 网页不列出备份目录中的 Markdown。Windows 保存遇到短暂占用时最多重试 0.5 秒，持续失败保留原记录并报错。Windows 服务独占端口，第二次启动不会抢占已有项目。

## 走查发现及修复

初次动作流程遇到 Windows `PermissionError`，旧 state 保持在上一个合法 revision；加入有限占用重试后，三案完整复测通过。启动走查随后复现 Windows 默认 HTTP 服务能重复绑定相同端口，改为独占绑定，并验证拒绝第二实例。最终启动检查发现 CMD 内中文在部分运行方式下会截断，改为 ASCII 批处理入口、Python 路径处理和独立中文提示文件。另修复了仅识别 Unity、初始化缺首步卡片、重复初始化指引和备份文档进入列表等问题。不是仅改标题后打包。

## 单独必要性审查

保留现有进度协议和门槛。新增内容服务于首次试用、可靠保存及干净交付；没有新建多套进度、自动引擎安装器、在线服务或大型类型框架。三案用少量代表场景检查引导和状态，不把制作三个完整游戏作为本轮试用包的交付条件，也不据此宣称已能自动完成所有游戏。

## 仍需实际试用确认

未验证全新客户电脑的安装全过程、其 Codex 账户/权限、真人能否理解全部步骤、长期制作效果，也未运行各引擎游戏、游戏构建、目标设备或发行。当前可交付的是“小范围试用版”，不是经过长期验证的稳定产品。建议先让少量使用者完成首次闭环并回传问题，再扩大发送。

工作流不会自动运行模型、发送资料、采购或发布。提供者的测试数据不进入新使用者的游戏进度。此报告不代表已经把 ZIP 发给任何人。
